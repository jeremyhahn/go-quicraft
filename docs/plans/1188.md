# Plan: ROADMAP Dependencies pins (#1188)

go-quicraft v0.20.0 and go-xkms v0.20.0 (indirect). An audit on 2026-11-20
found go-qrdb at v0.24.3 and go-xkms at v0.22.0. The roadmap goes stale
every time a consumer moves, so it should point to each consumer's `go.mod`
instead of copying version numbers.

- ROADMAP.md, Dependencies "Down:" bullet: keep the consumer names and the
  direct/indirect split; drop every copied version number; name each
  consumer's `go.mod` as the source of truth.
- Drop the stale "go-qrdb#695 adopts the newer go-quicraft tags (v0.23.0-alpha
  is tagged)" clause: go-qrdb is already past v0.23.0, so the clause no longer
  holds.
- This plan file.

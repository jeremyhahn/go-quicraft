# Plan for #948: dragonboat adapter snapshot control errors

Refs #744 (v1.0.0 bar test gap).

## Objective

Pin the documented snapshot error translation of every dragonboat state
machine adapter (regular, concurrent, on-disk) in
`contrib/dragonboat/statemachine/adapters.go`:

- SaveSnapshot: `ErrSnapshotStopped`, `ErrSnapshotAborted` and
  `ErrSnapshotStreaming` (bare or wrapped with `%w`) pass through unwrapped;
  any other error becomes `*AdapterSnapshotSaveError` wrapping the cause.
- RecoverFromSnapshot: only `ErrSnapshotStopped` passes through; any other
  error, `ErrSnapshotAborted` included, becomes
  `*AdapterSnapshotRecoverError` wrapping the cause.

## Slices

1. `docs: plan for #948` (this file).
2. `test:` add `contrib/dragonboat/statemachine/adapters_control_errors_test.go`,
   a table over the three adapter kinds built through `WrapCreateFunc`,
   `WrapConcurrentCreateFunc` and `WrapOnDiskCreateFunc` with inner state
   machines that return a configured error:
   - (a) Save with each sentinel, bare and `%w`-wrapped: `errors.Is` the
     sentinel and not an `*AdapterSnapshotSaveError`;
   - (b) Save with another error: `*AdapterSnapshotSaveError` whose cause
     `errors.Is` it;
   - (c) Recover with `ErrSnapshotStopped`: returned unwrapped;
   - (d) Recover with `ErrSnapshotAborted` or another error:
     `*AdapterSnapshotRecoverError` wrapping it.
3. Per divergence from the docs: a failing `test:` commit, then a `fix:`
   commit in `adapters.go` (or a doc-comment fix where the code is right).

## Out of scope

- Other adapter methods (Update, Lookup, Open, Sync, Close, PrepareSnapshot).
- The quicraft engine's handling of the returned sentinels.
- Any wire or on-disk format change.

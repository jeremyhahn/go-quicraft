# #836: EmergencySeal on a live Host

## Objective

Prove what docs/multi-group-host/api.md (Encryption and the barrier) and
docs/multi-group-host/user.md (Emergency seal) promise: `Host.EmergencySeal()`
seals the barrier at once without draining, after which every key-using
operation fails with `ErrBarrierSealed` (an in-progress snapshot save
included), `IsSealed` reports true and `HealthCheck().Status` is `"sealed"`.
Today only the no-barrier and already-sealed cases are tested.

## Slices

1. `docs: plan for #836` (this file).
2. `test:` pkg/host_emergency_seal_test.go
   - TestEmergencySeal_LiveHost_RefusesKeyUsingOps: Host with a real
     `seal.Barrier` (createTestBarrier), one shard, entries committed;
     `EmergencySeal` returns nil; then `IsSealed()` is true,
     `HealthCheck().Status == "sealed"` and `BarrierSealed` is true, and
     `SyncPropose`, `SyncRead`, `SyncRequestSnapshot` each return an error
     matching `ErrBarrierSealed`.
   - TestEmergencySeal_DuringSnapshotSave: the state machine's SaveSnapshot
     blocks; `EmergencySeal` lands while the save is in flight; the save
     then fails with `ErrBarrierSealed` and no `snapshot-*` directory or
     `*.tmp` entry is left under the host directory.
3. Per divergence from the docs: a failing `test:` commit, then a `fix:`
   commit in pkg/host.go (or a doc correction when the code is right).

## Out of scope

- Unsealing after an emergency seal (the Host has no unseal call).
- Per-shard barriers (covered by host_barrier_sealed_admit_test.go).
- Any wire or on-disk format change.

## Review fix

- P1: the sealed-save leftover walk matched only `snapshot-*` and `*.tmp`, but a
  local save stages under `.save-*` (engine.SaveStageDirPrefix) holding
  `snapshot.dat`, so a broken failed-save cleanup would pass.
- `test:` the walk also reports any entry engine.IsSnapshotSaveStage claims and
  any `snapshot.dat`, and the replica's snapshot directory
  (engine.ReplicaSnapshotDir) is asserted to hold no save artifact.
- If that fails: a `fix:` in pkg/internal/engine/snapshot_pool.go removing the
  staging directory on a sealed-barrier failure.

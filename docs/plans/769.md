# #769: memory and concurrent KV state machines agree

Objective: prove `MemoryStore` and `ConcurrentStore` (pkg/sm/kv) give the
same answer for every command sequence, malformed commands included.

Slice 1 (this PR), pkg/sm/kv/parity_test.go:
- A decoder turns arbitrary bytes into a batched command stream: Put, Get,
  Delete, PutIfAbsent over a small key space (so keys collide), plus
  malformed commands (short, unknown op, key length past the data).
- Both stores apply the same batches; every Update result, every point
  Lookup/BytesLookup/BytesLookupInto, a ListQuery and GetHash must match.
- Each store saves a snapshot, recovered into a fresh store of the other
  kind; the full key/value set and hash must match. Snapshot bytes from both
  stores must be identical (both serialise the same state).
- TestStoreParity runs seeded random sequences; FuzzStoreParity fuzzes the
  byte stream with seeds covering every op and each malformed shape.
- A found divergence gets a failing test commit, then a fix commit.

Out of scope: wire or snapshot format changes, other state machines.

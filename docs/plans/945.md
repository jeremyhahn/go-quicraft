# Plan for #945: MaybeApplied on a real Host

Refs #744 (v1.0.0 bar test gap).

## Objective

pkg/errors.go documents that every failure delivered to a proposal after it
was handed to Raft is wrapped in `*MaybeAppliedError`, and that a failure
that provably happened before the hand-off is not. The classifier is tested
on constructed errors; this row checks the contract end to end on a Host
built by `newTestHost`-style setup with `testShardConfig`.

## Slices

1. `docs: plan for #945` — this file.
2. `test: ...` — pkg/host_maybe_applied_test.go, tests named
   `TestMaybeAppliedHost*`, on a state machine whose `Update` can be held on
   a channel and counts applies per command:
   - (a) refusals before Raft: a proposal to a paused shard
     (`ErrShardPaused`), an oversized payload (`ErrEntryTooLarge`), a
     proposal after `Drain` (`ErrDraining`) and after `Close` (`ErrClosed`)
     each match their error through `errors.Is` and report
     `MaybeApplied` false;
   - (b) with `Update` held, `SyncPropose` with a short deadline fails with
     `ErrTimeout`, `MaybeApplied` true, `Temporary` true; after release the
     command is applied exactly once;
   - (c) with `Update` held, a proposal pending when `StopShard` runs fails
     with `MaybeApplied` true;
   - (d) every wrapped error is wrapped once: the `*MaybeAppliedError`
     found by `errors.As` unwraps to an error that is not one.
3. Per divergence from the docs: a failing `test:` commit, then a `fix:`
   commit in pkg/host.go (or a doc correction in pkg/errors.go or
   docs/client-sessions/user.md where the code is right).

## Out of scope

- Config changes, session operations and reads (covered elsewhere or never
  wrapped).
- Multi-host leadership-change paths (pkg/host_applyfailfast_test.go).

# Plan for #969: raft-consensus guide checked examples

Refs #744 (v1.0.0 bar test gap).

## Objective

docs/raft-consensus/user.md shows Go blocks that no example compiles or
runs. Add pkg/example_raft_test.go (package quicraft_test) whose examples
end in `// Output:` blocks, so `go test` checks what the guide states, and
point each matching guide block at its example.

## Slices, in order

1. This plan.
2. Test commit: pkg/example_raft_test.go with
   - `ExampleNotLeader`: a wrapped `*NotLeaderError` yields its `LeaderID`
     (and `LeaderAddress` through `errors.As`); the bare `ErrNotLeader`
     sentinel matches with leader 0; an unrelated error does not match.
   - `ExampleMaybeApplied`: a submitted proposal's timeout
     (`*MaybeAppliedError` wrapping `ErrTimeout`) is true; a definite
     rejection (`ErrSystemBusy`) and a bare read timeout are false.
   - `ExampleHost_SyncReadBuf`: on a running single-node shard, a proposed
     value reads back through `SyncReadBuf` and the release func is called.
   - `ExampleConfig_Validate_leaseRead`: `LeaseRead` with `CheckQuorum`
     false returns `*config.LeaseReadRequiresCheckQuorumError` (matches
     `config.ErrLeaseReadRequiresCheckQuorum`); `ElectionRTT` below 5
     returns a `*config.ValidationError` naming `ElectionRTT`.
   Reuses `exampleHostConfig`, `waitReadReady`, `startExampleShard`.
   The guide blocks gain a pointer to each example.
3. Per divergence between code and guide: a failing test commit, then a fix
   commit in pkg/errors.go, pkg/host.go or pkg/config/ (or a guide
   correction where the code is right).

## Out of scope

The guide's other blocks (timing, rate limiter, worker pool, quiesce,
listeners, diagnostics); any wire or on-disk format change.

# #752: every exported identifier in a public package has a doc comment

## Review fix

- Gap: `undocumentedDecls` skipped a whole `GenDecl` once it had a doc, so a
  documented `type ( Foo struct{}; Bar struct{} )` block passed with neither
  type documented.
- Fix: the block-level exemption applies to `const` and `var` groups only. In a
  grouped `type (...)` block every exported `TypeSpec` needs its own doc; a
  standalone `type X ...` keeps using the `GenDecl` doc.
- Test: a negative fixture (documented grouped type block, undocumented types)
  asserts the gate reports both types; then doc comments for every exported
  grouped type the stricter gate finds.

# #759 review fix: batch overflow regression on every architecture

- Objective: the batch decoder's bound check regression must fail on the base on amd64 too.
- Slice 1 (test): pkg/batch/decode_bounds_test.go calls fits(math.MaxInt-4, 16, 32), which
  overflows the old `off+n > total` form on every architecture.
- Slice 2 (refactor): pkg/batch/decode.go moves both payload bound checks into `fits(off, n, total)`.
- Slice 3 (build): Makefile ci-cross runs `GOARCH=386 go test -run 'Overflow|Fits' ./pkg/batch/`.
- Out of scope: wire format, other packages.

## Review fix

- Gap: ci-cross's 386 test invocation inherits CGO_ENABLED=1 from the CI image, which has no
  32-bit C toolchain, so every ci-cross job failed before the regression ran.
- Fix: Makefile sets CGO_ENABLED=0 next to GOARCH=386, as the cross builds above it do.
- Check: `CGO_ENABLED=0 GOARCH=386 go test` and `go vet` on ./pkg/batch/ pass.

## Review fix (round 3)

- Finding: the ci-cross 386 test step lies outside the PR's file map and is redundant:
  TestFits_NoOverflowNearMaxInt uses values near math.MaxInt, so the old form overflows on amd64 too.
- Fix: drop the four added ci-cross lines so the Makefile matches main exactly; slice 3 is withdrawn.
- Check: `git diff main -- Makefile` is empty; `go test -race` and `go vet` on ./pkg/batch/ pass.

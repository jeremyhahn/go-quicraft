# #833: race sweep of the transport, session and storage helper packages

## Objective

A data race on main (#831) showed only under load during a coverage run, so
the normal `-count=1` unit run misses interleavings. Run the helper packages
under `-race` at high repetition, at the default GOMAXPROCS and at
`GOMAXPROCS=2`, and fix every race or flaky failure it finds.

Packages: `pkg/internal/{golden,invariant,netaddr,queue,registry,rsm,server,session,supervise,transport}/...`,
`pkg/batch/...`, `pkg/sm/...`, `pkg/writemode/...`. The Makefile's unit run
(`GOTEST`, `coverage-shard`) uses `-race` and no build tags by default, so
the sweep uses no tags either.

## Slices, in order

1. This plan.
2. The sweep:
   `go test -race -count=20 <packages>`, then the same with `GOMAXPROCS=2`.
3. Per race or flaky failure: a `test: <the race> reproduces` commit with a
   test that fails on the current code (deterministic where possible), then
   a `fix: <the race>` commit that makes it pass.
4. `docs: race sweep results for #833`: every command, its duration and
   its result, below, including a clean result.

## Out of scope

- A race in `pkg/host.go`'s pending-read path: that is #831's; noted only.
- Any package outside the list above, and any wire or on-disk format
  version change.

## Slice 2

Slice 1 swept `golden`, `invariant`, `netaddr`, `queue` and `supervise`
(one finding: the supervise contained-diagnostics bound check). Slice 2
sweeps, one package at a time, at the default GOMAXPROCS and at
`GOMAXPROCS=2`: `pkg/internal/{registry,rsm,server,session,transport}/...`,
`pkg/batch/...`, `pkg/sm/...`, `pkg/writemode/...`; and
`pkg/internal/{invariant,netaddr,queue}/...` at `GOMAXPROCS=2` only.

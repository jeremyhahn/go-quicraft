# Plan for #918: WireWindow and IsCleanRefusal direct tests

Tracked under #744 (v1.0.0 bar test gap).

## Objective

Give the exported wire-window helpers in pkg/proto and
`waldb.IsCleanRefusal` direct tests that pin each to its doc comment.

## Slices

1. `pkg/proto/wirewindow_test.go`:
   - `Accepts` is true for Current and Previous and false for 0,
     Current+1 and max uint64, on `DefaultWireWindow()` and on {3, 2}.
   - `EffectiveWireVersion(0)` is `PreviousWireVersion`; any other v is v.
   - On {3, 2}: `CheckCommit` is nil for (0,2), (0,3), (2,3), (3,3) and
     `ErrUnsupportedVersion` for (3,2) (a revert), (0,4) and (0,1).
   - `DefaultWireWindow()` is {WireVersion, PreviousWireVersion} and
     `AcceptsWireVersion` agrees with it.
   - `Entry.IsInitialMembership` is true for `EntryInitialMembership` with
     and without `EntryCompressFlag`, false for normal, config change and
     metadata entries.
2. `pkg/logdb/waldb/clean_refusal_test.go`: `IsCleanRefusal` is true for
   the cause and for the cause wrapped with `%w`; false for nil, an
   unrelated error, `errors.Join(cause, ErrDBPoisoned)`, a
   `*BatchWriteError` or `*WALWriteError` wrapping the cause, and either of
   those wrapped again.
3. Per divergence from the docs: a failing test commit, then a fix commit
   in pkg/proto/constants.go or pkg/logdb/waldb/errors.go.

## Out of scope

- Any change to a wire or on-disk format version.
- Callers of these helpers (host, engine); they are read only for context.

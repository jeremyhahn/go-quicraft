# Row #1122: seal-barrier

## Objective

Fold the SPEC row `seal-barrier`'s open per-issue PRs into the one row
branch `row/1122-seal-barrier`, ported onto current main, so that one PR
closes #1122. Each folded PR keeps its own commit, titled with the PR's
title plus "(folds #N)".

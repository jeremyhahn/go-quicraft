# #832: engine, raft and log storage pass -race at high repetition

## Objective

A data race on main (#831) showed only under load during a coverage run;
the normal `-count=1` race run misses rare interleavings. Sweep the engine,
raft and log storage packages under the race detector at high repetition,
at the default GOMAXPROCS and at `GOMAXPROCS=2`, and fix every race or
flaky failure at its root cause.

## Slices, in order

1. This plan.
2. Sweep:
   - `go test -race -count=20 ./pkg/internal/engine/... ./pkg/internal/raft/... ./pkg/logdb/...`
   - the same with `GOMAXPROCS=2`.
3. Per finding: a `test: <the race> reproduces` commit with a test that
   fails under `-race` (deterministic where possible), then a
   `fix: <the race>` commit that removes the root cause.
4. `docs: race sweep results for #832`: every command, its duration and
   its result (a clean result included) in the table below.

## Acceptance

- `go test -race -count=20` over the three package trees passes.
- `go vet` passes on every package in scope.
- `git diff --name-only f01d610b..HEAD` lists only this plan and the
  test and source files under pkg/internal/engine/, pkg/internal/raft/
  and pkg/logdb/ that hold a race.

## Out of scope

- The race in pkg/host.go's pending-read path: that is #831's; noted in
  the results only.
- Any wire or on-disk format version change.
- Packages outside the three trees above.

## Results

Run 2026-11-12 on main f01d610b plus this plan (80 logical CPUs).
`PKGS` = `./pkg/internal/engine/... ./pkg/internal/raft/... ./pkg/logdb/...`.

| Command | Duration | Result |
|---|---|---|
| `go test -race -count=20 -timeout=3600s $PKGS` | 299 s | rc 0, all 5 packages ok, no race reported |
| `GOMAXPROCS=2 go test -race -count=20 -timeout=3600s $PKGS` | 387 s | rc 0, all 5 packages ok, no race reported |
| `go vet $PKGS` | 11 s | rc 0, no findings |

Per-package wall time, default / GOMAXPROCS=2: engine 287 s / 294 s,
raft 76 s / 74 s, logdb 9 s / 11 s, logdb/memdb 2 s / 2 s,
logdb/waldb 268 s / 297 s.

Findings: none. Neither sweep reported a race or a flaky failure, so
slice 3 (test and fix commits) produced no commits.

Not covered here: the race in pkg/host.go's pending-read path is #831's
and outside these package trees.

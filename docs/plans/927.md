# Plan for #927: RequestLeaderTransfer target results

Refs #744 (v1.0.0 bar test gap).

## Objective

`docs/multi-group-host/api.md` (Leader transfer) documents the result of
`Host.RequestLeaderTransfer` for each kind of target. Observer, removed and
follower cases are already tested; target 0, the leader itself, a witness and
an unknown replica are not. Pin every documented result with a test.

## Slices

1. `pkg/host_leader_transfer_targets_test.go` (new), on a single-voter shard
   (`startSingleVoterShard`):
   - target 0 returns `*InvalidMemberError` (via `errors.As`) naming replica 0;
   - the leader's own replica ID returns nil and the leader stays replica 1;
   - an ID not in the membership returns `*ReplicaNotFoundError` that
     `errors.Is` matches to `ErrReplicaNotFound`;
   - a witness added with `SyncRequestAddWitness` returns
     `*InvalidMemberError` naming the witness;
   - an unknown shard returns `ErrShardNotFound`;
   - a closed Host returns `ErrClosed`.
2. Per divergence between code and docs: a failing test commit, then a fix
   commit in `pkg/host.go` (or a doc fix in `docs/multi-group-host/api.md`
   where the code is right).

## Out of scope

- The asynchronous outcome of a valid transfer (covered elsewhere).
- Observer, removed and follower targets (already tested).

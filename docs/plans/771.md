# Plan: #771, the Dragonboat NodeHost method table

Objective: contrib/dragonboat/README.md lists every exported `NodeHost` method,
whether Dragonboat v4 has it, how it behaves differently, and every Dragonboat
v4 `NodeHost` method the shim does not provide; a test keeps the table in step
with the code.

Slices, in order:

1. This plan.
2. The table in contrib/dragonboat/README.md, built from the shim's method set
   and doc comments diffed against Dragonboat v4's `NodeHost` method set, and
   `contrib/dragonboat/readme_table_test.go`: it parses the package's non-test
   Go files for exported `*NodeHost` methods, parses the README table, and fails
   when a method is missing from the table or the table names a method the
   package does not export.

docs/compatibility covers API compatibility of QuicRaft's own releases and has
no Dragonboat section, so it is not edited.

Out of scope: changing any method's behaviour; types other than `NodeHost`.

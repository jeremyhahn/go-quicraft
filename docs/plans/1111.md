# #1111 raft-consensus (SPEC row)

## Objective

Fold the row's open per-issue test PRs onto one row branch,
`row/1111-raft-consensus`, from current main, so they build and pass
together and land as one PR that closes #1111. Test files (and guide
text where listed) only; no non-test code changes.

## Slices (one commit per folded PR, in this order)

1. #1077 (#1065) `pkg/internal/raft/quiesce_state_test.go`: quiesceState
   derives threshold and liveness interval from the election timeout,
   enters quiesce on exactly the threshold-th idle tick, never counts when
   disabled or already active; recordActivity restarts the count.
2. #994 (#956) `pkg/internal/raft/stale_config_timeout_now_test.go`: a
   TimeoutNow on a replica whose committed configuration tail cannot be
   resolved returns ErrStaleConfigCannotCampaign and starts no election.
3. #993 (#955) `pkg/internal/raft/reserved_entry_type_test.go`: the leader
   refuses a batch carrying EntryInitialMembership or EntryMetadata with
   ErrReservedEntryType and appends none of it.
4. #928 (#902) `pkg/concurrent_propose_leaderchange_test.go`,
   `pkg/concurrent_propose_test.go`: TestConcurrentPropose_ classifies
   SyncPropose errors across a leader change.
5. #927 (#957) `pkg/config/safety_flags_test.go`: CheckQuorum, PreVote and
   OrderedConfigChange getters default to true; Validate warns once per
   safety flag explicitly turned off.
6. #914 (#969) `pkg/example_raft_test.go`, `docs/raft-consensus/user.md`:
   the guide's error checks and config rules run as checked examples.
7. #865 (#917) `test/integration/host/quiesce_test.go`: a quiesced idle
   shard keeps its leader and wakes on the next proposal.

## Out of scope

- The per-issue docs/plans files of the folded PRs (this file replaces
  them).
- Any non-test code change; a test that shows the code is wrong is
  reported, not fixed, in this slice.

# #1111 raft-consensus (SPEC row)

## Objective

Fold the row's open per-issue test PRs onto one row branch,
`row/1111-raft-consensus`, from current main, so they build and pass
together and land as one PR that closes #1111. Test files (and guide
text where listed) only; no non-test code changes.

## Slices (one commit per folded PR, in this order)

1. #1077 (#1065) `pkg/internal/raft/quiesce_state_test.go`: quiesceState
   derives threshold and liveness interval from the election timeout,
   enters quiesce on exactly the threshold-th idle tick, never counts when
   disabled or already active; recordActivity restarts the count.
2. #994 (#956) `pkg/internal/raft/stale_config_timeout_now_test.go`: a
   TimeoutNow on a replica whose committed configuration tail cannot be
   resolved returns ErrStaleConfigCannotCampaign and starts no election.
3. #993 (#955) `pkg/internal/raft/reserved_entry_type_test.go`: the leader
   refuses a batch carrying EntryInitialMembership or EntryMetadata with
   ErrReservedEntryType and appends none of it.
4. #928 (#902) `pkg/concurrent_propose_leaderchange_test.go`,
   `pkg/concurrent_propose_test.go`: TestConcurrentPropose_ classifies
   SyncPropose errors across a leader change.
5. #927 (#957) `pkg/config/safety_flags_test.go`: CheckQuorum, PreVote and
   OrderedConfigChange getters default to true; Validate warns once per
   safety flag explicitly turned off.
6. #914 (#969) `pkg/example_raft_test.go`, `docs/raft-consensus/user.md`:
   the guide's error checks and config rules run as checked examples.
7. #865 (#917) `test/integration/host/quiesce_test.go`: a quiesced idle
   shard keeps its leader and wakes on the next proposal.

## Review fixes (rc1111b)

8. `pkg/concurrent_propose_test.go`: the pre-restart check keeps only the
   duplicate, refused and unsubmitted-key checks; restart closes hosts one
   at a time and an in-flight MaybeApplied proposal may still apply on the
   remaining quorum, so replica-to-replica equality moves to
   concurrentProposeCheck, after the restart fence and final barrier.
9. `test/integration/host/quiesce_test.go`: a per-host test
   MetricsCollector counts Heartbeat/Quiesce sends and Quiesce receipts;
   before each wake, read and failover phase the test waits for the
   leader's Quiesce broadcast, every follower's receipt, and a suppressed
   heartbeat cadence (at most one liveness probe per follower in three
   election timeouts). With Quiesce off the wait fails.

## Review fixes and PR merges (rc1111b, second slice)

10. `pkg/concurrent_propose_test.go`: restart fences every live replica
    at the acknowledged prefix (its own workload state machine has
    applied every acknowledged key) before any host closes, and the
    pre-restart check again requires each acknowledged key exactly once
    on every live replica, before replay could repair a skipped apply.
11. `pkg/concurrent_propose_leaderchange_test.go`: the stopped-former-
    leader warm-up retries when its forward races an early leader change.
12. `test/integration/host/quiesce_test.go`: phase (a) stays quiesced past
    the followers' extended election timeout and requires one liveness
    probe per interval; heartbeats are counted on receipt (the heartbeat
    send fast path does not report IncMessagesSent), after an active-phase
    check that the counter sees them.
13. Merge commits for PRs #865, #876, #904, #914, #921, #927, #928, #993,
    #994, #1077. Heads already folded resolve to the row's version;
    #876, #904 and #921 add their test files.

## Out of scope

  them).
- Any non-test code change; a test that shows the code is wrong is
  reported, not fixed, in this slice.

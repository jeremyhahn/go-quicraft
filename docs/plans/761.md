to fail. Prove the detection works against a planted leak.

Slices, in order:

1. Factor the poll loop out of runHostLifecycleLeakCheck into a helper,
   leakedModuleGoroutines(before, self, wait), that polls
   moduleGoroutinesSince (stack snapshot + leftover filter) until nothing
   new is left or the deadline passes, and returns what is left.
2. Add TestHostGoroutineLeak_DetectsPlantedLeak: start a goroutine in a
   function declared in the test file that blocks on a channel, run the
   helper with a short deadline, assert it reports exactly that goroutine;
   release it and assert the helper reports nothing.

dependencies; fixing leaks in the Host itself.

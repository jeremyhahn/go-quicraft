# Plan for #928: unauthorized-drop reasons removed_replica, removed_identity, misrouted

Refs #744 (v1.0.0 bar test gap).

## Objective

docs/observability/architecture.md documents six reasons for
`SecurityMetrics.IncUnauthorizedMessageDropped`. Three of them
(`unknown_member`, `identity_mismatch`, `missing_identity`) are asserted by
pkg/messagehandler_identity_test.go. The other three, counted by
`hostMessageHandler.authorizeInbound` in pkg/messagehandler.go, have no test
that drives a message to them: `removed_replica`, `removed_identity`,
`misrouted`. This row adds that test.

## Slices

1. Plan (this file).
2. Test: pkg/messagehandler_drop_reasons_test.go, built on `identityRig`
   style helpers (a real engine node restored from a membership snapshot,
   a recording deliverer) and a collector embedding `NoOpMetricsCollector`
   that records every `IncUnauthorizedMessageDropped(shardID, from, reason)`.
   - (a) a message from a replica the committed membership has removed,
     under its own ID, is not delivered; one count, `removed_replica`.
   - (b) a connection whose authenticated identity is a removed replica's,
     claiming another current member's ID, is not delivered; one count,
     `removed_identity`, never `identity_mismatch`.
   - (c) a message whose `To` names another replica of this shard is not
     delivered; one count, `misrouted`.
   - (d) each count carries the message's shard ID and claimed `From`; a
     valid message from a current member in the same batch is delivered
     and counts nothing.
3. Per divergence from the docs: a failing test commit, then a fix commit
   in pkg/messagehandler.go (or a doc fix in
   docs/observability/architecture.md where the code is right).

## Out of scope

- The three reasons already covered, the pending-removal path, and the
  Prometheus collector's label set.
- Any wire or on-disk format change.

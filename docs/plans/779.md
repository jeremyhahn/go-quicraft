# #779: a repeated session proposal applies once across a leader change

Objective: prove on an in-process three-replica shard that a session retry with
the same (clientID, seriesID) sent to a new leader after a leadership transfer
is applied once and answered with the first result, and that a retry below the
session's responded-to watermark is refused with `*SessionExpiredError`.

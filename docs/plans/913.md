# Plan for #913: StopReplica end to end

Refs #744 (v1.0.0 bar test gap).

## Objective

docs/multi-group-host/api.md (Replica management) and
docs/membership-changes/api.md (local, destructive replica operations) say
`StopReplica(shardID, replicaID)` checks that `replicaID` is this host's
replica of the shard and then stops it like `StopShard`: a different loaded
replica ID returns `*ReplicaNotFoundError` (matches `ErrReplicaNotFound`), a
shard that is not loaded returns `ErrShardNotFound`, a closed host returns
`ErrClosed`, and `HasNodeInfo` reports the bootstrap record in the log store.
The only success test checks the error alone. This row pins the behaviour on
a real Host with a real WAL.

## Slices

1. `docs: plan for #913` (this file).
2. `test:` pkg/host_stop_replica_test.go, a transportless Host
   (`WithoutTransport()`, `WithoutEncryption()`, real WAL from
   testHostConfig) running hashingCreateFunc:
   - (a) after 20 SyncPropose calls, `StopReplica(1, 2)` returns a
     `*ReplicaNotFoundError` with ShardID 1 and ReplicaID 2 that matches
     `ErrReplicaNotFound`; the shard still serves a SyncPropose and
     `ShardInfo(1)` still reports replica 1;
   - (b) `StopReplica(1, 1)` returns nil; SyncPropose on shard 1 then fails
     with `ErrShardNotFound`; a second `StopReplica(1, 1)` returns
     `ErrShardNotFound`; `HasNodeInfo(1, 1)` is still true;
   - (c) StartShard of the same replica on the same Host recovers: after
     waitForLeader, `StateMachineHash` reports an applied index at least the
     last acknowledged proposal's index and the same hash, and a new
     SyncPropose succeeds;
   - (d) after Close, `StopReplica(1, 1)` returns `ErrClosed`.
3. Per divergence found: a failing `test:` commit, then a `fix:` commit in
   pkg/host.go (or a doc correction in docs/multi-group-host/api.md when the
   code is right and the doc is wrong).

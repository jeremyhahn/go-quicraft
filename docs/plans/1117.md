# Row #1117: snapshots

## Objective
Fold the `snapshots` SPEC row's open per-issue PRs into one row branch,
`row/1117-snapshots`, rebased on current main, all passing together, and
land them as one PR that closes #1117. Per-issue docs/plans files are not
carried over; this file is the row's one plan.

## Slices (one commit per folded PR, in this order)
1. #1101 pkg/host_import_typed_errors_test.go: ImportSnapshot layout,
   DataDir and out-of-date refusals are typed errors naming the shard,
   replica and conflicting values.
2. #1083 pkg/proto/snapshotfile_contract_test.go: SnapshotFile codec
   refuses overlong fields before the buffer check, and truncated records.
3. #1082 pkg/internal/rsm/after_capture_test.go: SaveSnapshotGated calls
   afterCapture only after capture; a failed save leaves Apply unblocked.
4. #1078 pkg/snapshot_option_validate_test.go: SnapshotOption.Validate
   accepts/refuses with exact messages.
5. #1075 pkg/internal/engine/epoch_pinner_test.go: epochPinner pins one per
   distinct epoch, first-seen order, ignores epoch 0.
6. #1034 pkg/internal/engine/node_snapshot_dir_holds_test.go: snapshot-dir
   pins nest and clean paths; GCSparedSnapshotDirs lists them.
7. #1021 pkg/internal/transport/errors.go (doc comments only),
   pkg/internal/transport/snapshot_write_error_test.go: a failed chunk
   write names shard, replica and chunk and wraps the stream error.
8. #995 pkg/internal/engine/snapshot_frame_writer_closed_test.go: Write
   after Close is ErrSnapshotFrameWriterClosed; second Close is a no-op.
9. #926 pkg/snapshot_option_overhead_test.go: OverrideCompactionOverhead
   keeps exactly CompactionOverhead entries. Departure: its after-restart
   check wanted the same FirstIndex, which failed on its own PR head; on
   restart the log reader is rebuilt from the snapshot marker
   (pkg/logdb/reader.go ApplySnapshot), so the retained entries are not
   reloaded. The check now wants FirstIndex >= the compacted first index.
10. #915 docs/snapshots/user.md, pkg/example_snapshot_test.go: the guide's
    request, export and import flows run as checked examples.
11. #896 pkg/host_auto_snapshot_test.go: automatic snapshots every
    SnapshotEntries; SnapshotsDisabled never snapshots.
12. #890 pkg/internal/engine/snapshot_reader_test.go: decompressing and
    hashing snapshot readers.

31. Review scope, re-measured: the row diff against merge base 83e47bdf is

    logdb and engine-snapshot tests and the grow/shrink, CRL and quiesce
    suites are not in it (they reached this branch from main, rows #1143

    - quic-go v0.65.0 queued-shutdown trace, verified from the module
      source: Listener.Close calls baseServer.close(ErrServerClosed,
      false), which closes errorChan, waits for handshakingCount and closes
      stopAccepting, but does not drain connQueue (only a transport close
      does). accept drains connQueue after stopAccepting and then returns
      closeErr, so closeQueuedOnShutdown's uncancelled Accept loop ends.
      With a done ctx and a non-empty queue, the select may pick ctx (why
      the drain carries no deadline). handleNewConn's select between
      errorChan and HandshakeComplete may refuse a handshake-complete
      connection that is not yet queued: this is why the test waits for
      acceptQueueLen == n, not only for handshake confirmation.
    - Read in full, no defect: test/integration/host/full_cluster_restart_test.go
      (main test, singleLeader) and partial_placement_test.go.

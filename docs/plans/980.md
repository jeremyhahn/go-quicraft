# Plan for #980: identity-less add calls on a dragonboat NodeHost with a transport

Refs #744 (v1.0.0 bar test gap).

## Objective

contrib/dragonboat/nodehost.go documents that a NodeHost with a transport
refuses the add calls that commit no node identity (`SyncRequestAddReplica`,
`SyncRequestAddNonVoting`, `SyncRequestAddWitness`, `RequestAddReplica`,
`RequestAddNonVoting`, `RequestAddWitness`) with
`quicraft.ErrMemberIdentityRequired`. No contrib test checks that error.
This row adds one integration test that does, and fixes the code or the doc
comment where the two disagree.

## Slices, in order

1. `docs: plan for #980` - this file.
2. `test: ...` - contrib/dragonboat/test/integration/identity_required_test.go,
   `TestIntegration_DB_IdentityRequired`, on a three-host `newDBTestCluster`
   with shard 1 started and a warmup entry committed:
   - (a) each Sync add call for a new replica ID, issued on the current
     leader with the current `ConfigChangeID`, returns an error for which
     `errors.Is(err, quicraft.ErrMemberIdentityRequired)` holds;
   - (b) each async add call returns that error at once with a nil
     RequestState, or a RequestState whose result is not `Completed()`;
   - (c) the linearizable membership read afterwards shows the same
     `ConfigChangeID` and none of the IDs in `Nodes`, `NonVotings` or
     `Witnesses`;
   - (d) the `WithIdentity` add for the same non-voting ID then lands, so the
     refusal left no pending change behind.
   Each probe is re-issued only while the answer is a not-leader refusal, on
   the replica leading at that moment; every new helper takes
   `context.Context` first, before `*testing.T`.
3. Per divergence from the docs: a failing `test:` commit, then a `fix:`
   commit in contrib/dragonboat/nodehost.go or contrib/dragonboat/errors.go
   (or the doc comment corrected there when the code is right).

## Out of scope

- The quicraft (pkg) Host forms of these calls; they have their own tests.
- Delete calls, which carry no identity by design.
- Any wire or on-disk format change.

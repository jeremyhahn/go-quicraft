# #749: package examples

## Review fix: examples persist durably and build a valid host

1. `pkg/sm/example_test.go`: the disk state machine example writes its state
   file through one `writeStateFile` helper (temp file in the same directory,
   fsync, rename over the state file, fsync the directory), used by Sync and
   RecoverFromSnapshot. Test: `go test -run Example ./pkg/sm/`.
2. `contrib/dragonboat/example_test.go`: ExampleNewNodeHost sets MutualTLS
   and the CA, certificate and key files the caller provides. Test:
   `example_config_test.go` builds the same config with generated
   certificates and asserts NewNodeHost succeeds and Close returns.

## Review fix

1. `pkg/sm/example_test.go`: fileStore.Update skips entries at or below the
   applied index, as DiskStateMachine requires idempotent replay. The example
   replays an applied entry after reopening and its Output: shows the restored
   value and index unchanged. Test: `go test -run Example ./pkg/sm/`.
2. `pkg/crypto/shamir/example_test.go`: the comment says CombineBytes returns
   CombineError for fewer values than the threshold, and garbage comes from
   corrupted or mismatched shares or a threshold below the split threshold;
   the example only prints the secret. Test: `go test -run Example ./pkg/crypto/shamir/`.

## Review fix: rejected commands and one batch publication

1. `contrib/dragonboat/example_test.go`: kvStore.Update answers a command
   without '=' with `sm.Result{Data: []byte("malformed command")}` and a nil
   error, so a bad proposal cannot fail the shard. Test:
   TestKVStore_MalformedCommandThenValid; ExampleNodeHost_SyncPropose prints
   the rejection of "garbage" before "greeting=hello".
2. `pkg/sm/example_test.go`: register.Update stores only the batch's final
   valid value, once. Test: TestRegister_BatchPublishesOnce; the example's
   second put is a two-entry batch.

# Plan for #906: the inspection views agree on a quiescent shard

Tracked under #744 (v1.0.0 bar test gap).

## Objective

docs/raft-consensus/api.md ("inspect consensus state") and
docs/multi-group-host/api.md (diagnostics, `ReadonlyLogReader`) describe
several read-only views of one replica's state. Each is tested alone; this
row adds one test that checks they agree with each other.

## Slices

1. This plan.
2. `pkg/host_inspection_agree_test.go`: `TestHost_InspectionAgree` on a
   single-voter transportless Host (`newTestHost`, `testShardConfig`,
   `hashingCreateFunc`, `waitForLeader`, `waitForDiagLive`). It waits until
   the shard is quiescent (applied index and the published diagnostics
   snapshot stable across reads), samples every view, runs 25 more
   `SyncPropose` calls, waits for quiescence again and samples again.
   Per sample it asserts:
   - (a) `LogRange().LastIndex` == `LogReader().GetRange()` last index ==
     `LogReader().NodeState()` last index == `DiagRaftState().LastIndex`;
   - (b) `DiagRaftState().Processed` == the applied index from
     `StateMachineHash`, and on a quiescent single voter
     `DiagRaftState().Committed` == `LastIndex` == applied index;
   - (c) `DiagRaftState().Term` == the `LeaderIDAndTerm` term == the
     `ShardReadReady` term == the `NodeState` term; the leader ID from both
     is 1, `ShardReadReady` reports ready, and `DiagRaftState().State`
     starts with "leader".
   Between the two samples:
   - (d) LastIndex, Committed and the applied index each grew by exactly
     25, and the term did not change.
3. Per divergence from the docs: a failing test commit, then a fix commit
   in pkg/host.go or pkg/log_reader.go (or a doc fix in
   docs/multi-group-host/api.md where the code is right).

## Departure from the brief

The brief asks for "`NodeState` commit". `ReadonlyLogReader.NodeState`
returns `(lastIndex, term)` in both the code (pkg/log_reader.go) and the
docs (docs/multi-group-host/api.md, `ReadonlyLogReader`); it has no commit
index. The test checks `NodeState`'s last index and term instead, and checks
`Committed` against the log's last index, which a quiescent single voter
must have committed.

## Out of scope

Multi-replica agreement (followers lag by design), witnesses and
observers, `ShardInfo`, `QueryRaftLog` and `HealthCheck`.

`InMemoryInvocationCounter` (pkg/seal/aead_tracking.go).

## Status

Already delivered on main by PR #1107 (commit 65b5993a), which used
`Refs #1073` and so left the issue open. Its tests in
`pkg/seal/aead_tracking_edges_test.go` cover each expected assertion:

- `TestNonceTrackingEdge_NonPositiveCeilingRemovesBound`: ceiling 0 / -1
  records five distinct nonces and never saturates.

  false, Saturated false; CheckAndRecordNonce and Clear return nil.

  saturation, keeps Count/Contains; re-enabled tracker rejects a retained
  nonce.

  1000 gives usage <= 100 and ShouldRotate true.

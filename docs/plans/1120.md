# Row #1120: write-batching

## Objective

Row #1120 is the SPEC row `write-batching` of docs/SPEC.md. One branch
(`row/1120-write-batching`), one PR that closes #1120. The row's open
per-issue PRs are folded into this branch from current main and pass
together. Per-issue docs/plans files are not carried over.

## Slices (in order, one commit each)

1. Fold #1079 (`issue/1069-batch-flush-outcome-counters`):
   `pkg/batch/flush_counters_test.go`. The batch aggregator counts each
   flush in batches_total as attempted plus success or failed, records
   batch_size per proposed batch, and labels the series.
2. Fold #921 (`row/956-batch-config-nocopy-errors`):
   `pkg/batch/config_nocopy_errors_test.go`. batch.DefaultConfig holds the
   documented defaults, WithConfig keeps a default for every zero field,
   and SubmitNoCopy returns the same errors as Submit.
3. Fold #910 (`row/963-write-batching-examples`):
   `docs/write-batching/user.md`, `pkg/batch/example_test.go`,
   `pkg/writemode/example_test.go`. The guide's DecodeBatch, FlushError
   handling and writemode snippets are compiled examples with checked
   output.
4. Fold #873 (`row/921-batch-aggregator-host`):
   `pkg/host_batch_aggregator_test.go`. A batch Aggregator on a real Host
   applies every concurrently submitted command exactly once in fewer
   entries than commands.

Each slice: `go test -race` on the touched package, `-count=3` on the new
tests, gofmt clean.

## Out of scope

- Non-test code changes. A test that shows the code is wrong is reported,
  not fixed, in this slice.
- The per-issue plan files of the folded PRs.
- Opening the PR (the coordinator's train opens it).

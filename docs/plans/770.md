# #770: every exported Host method returns ErrClosed after Close

Objective: prove that once `Close` returns, every exported `*Host` method
either returns an error matching `ErrClosed` or is a getter documented as
safe after Close, and that none panics or blocks.

Slices, in order:

1. `pkg/host_closed_test.go`: build a memory-backed Host, close it, list the
   exported methods of `*Host` by reflection and call each with arguments
   built from its parameter types (an explicit override table where a type
   needs a real value). Each method must be classified in a table
   (`closedErr` or `getter`); an unclassified method fails the test, so a
   new method is covered by default. Every call runs under a deadline and
   recovers panics.
2. `TestHostClosedCloseIdempotent`: Close from several goroutines at once
   under `-race`, then again; every call returns without panic.
3. Per method found not to honour ErrClosed: a failing test commit, then the
   fix in `pkg/host.go` or `pkg/leaderexec.go`.

Out of scope: behaviour during Close (in-flight work), wire/on-disk formats.

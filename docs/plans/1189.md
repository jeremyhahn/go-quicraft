# #1189: ci.yml v1.53 (ci.yml-only)

## Objective

Adopt the handbook ci.yml template v1.53 (handbook commit 96e8e623) in
`.github/workflows/ci.yml` as a ci.yml-only change on main: main's
concurrency group becomes `main-{event}` and v1.52's fork-aware runner
selection is taken, keeping every CUSTOMIZE block.

## Slices

1. Concurrency (v1.53): `concurrency.group` equals the template's line at
   96e8e623; the template's v1.53 comment goes above `concurrency:`.
2. Runner selection (v1.52): a fork's pull request runs every job on
   `ubuntu-latest`; this repository's runner values are kept.
3. Header: line 1 names `ci-template: v1.53 (customized)`, with v1.52 and
   v1.53 lines naming what was taken.
4. Tests: test/buildgates/ci_runners_test.go gains a fork-routing case
   (every ci.yml job resolves to `ubuntu-latest` for a fork pull request)
   and a concurrency case (main's group is `main-{event}`).

## Out of scope

code-review.yml and every other workflow; the rest of the v1.36 to v1.51
catch-up named in ci.yml's header.

## ci.yml v1.53 (ci.yml-only)

- Handbook commit: 96e8e623 (`ci-template: v1.53`); v1.52 is 2635447.
- Taken from the template:
  - v1.53: `concurrency.group` is the template's line exactly (main is
    `main-{event}`, schedule stays `schedule-{repository}`,
    `cancel-in-progress: true` literal), with the template's v1.53 comment
    above `concurrency:` ahead of the v1.26.2 paragraph, as the template
    has it.
  - v1.52: its outcome, a fork's pull request runs every job on
    `ubuntu-latest`. This repository's runner value for every ci.yml job is
    the literal `ubuntu-latest` (hosted first), so the template's selection
    with these values gives `ubuntu-latest` to forks, same-repository pull
    requests and main alike.
  - Header: line 1 `ci-template: v1.53 (customized)`, with v1.53 and v1.52
    lines naming what was taken.
- CUSTOMIZE blocks kept: all (none removed; count not lower than main's 76).
- Kept from main:
  - each job's literal `runs-on: ubuntu-latest` in place of the template's
    runs-on expressions: ci_runners_test.go refuses an expression runs-on
    in ci.yml, since one can pick a self-hosted label;
  - the template's `Hosted or overflow runner (ruling 1024)` step is not
    added: with no self-hosted runner allowed it has nothing to select, and
    it needs HOSTED_JOBS_PER_REPO and HOSTED_QUEUE_GRACE_SECONDS, which
    main's env does not have;
  - the template's inline `Runner labels (ruling 633)` step is not added:
    test/buildgates/ci_runners_test.go is this repository's runner check.
- Tests changed: test/buildgates/ci_runners_test.go adds
  TestCIForkPullRequestRunsHosted (every ci.yml job resolves to
  `ubuntu-latest` for a fork's pull request; a self-hosted label and a
  runs-on expression are each one finding) and
  TestCIConcurrencyGroupIsMainPerEvent (the group equals the template's,
  cancel-in-progress a literal true). No other test pinned the changed text.

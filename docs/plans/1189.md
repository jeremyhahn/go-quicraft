## Review fixes (PR #1191)

1. `make docker-make` ran offline: the default `ci` target lints the
   benchmark modules and runs govulncheck and Trivy, which download, but
   scripts/in-toolchain-image.sh defaults to no network. Fix:
   `DOCKER_MAKE_NETWORK ?= bridge`, passed as IN_IMAGE_NETWORK;
   `DOCKER_MAKE_NETWORK=none` keeps an offline run. Comment and help updated.
2. The ci.yml image-history checks keyed on `env.IT_LEASE_ID`, which no
   step sets, so they never ran. Fix: the image job's toolchain check runs
   on TOOLCHAIN_IMAGE alone, and a new step checks IT_IMAGE after the
   build. The integration job never builds IT_IMAGE (it reuses the image
   job's), so its one check (the two identical steps merged) runs on
   `env.IT_IMAGE != '' && env.IT_LEASE != ''`: the lease is set only when
   the image is on the host, so the check never fails on a missing image.
   The soak job had no check and still has none.
   New test test/buildgates/image_history_test.go: every variable an
   image-history step reads is set by an earlier step or an env: block; it
   failed on the old ci.yml (IT_LEASE_ID) and passes on the new one.

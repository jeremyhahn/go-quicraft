# Plan: #951 state machine user guide snippets as package examples

## Objective

docs/state-machines/user.md shows a `Counter` state machine, its registration
through `sm.NewCreateFunc`, a `GetHash` with a compile-time `sm.Hasher` check,
and a `sm.NewCachedDiskStateMachine` built from a `sm.CacheConfig`. None of
these snippets is compiled. Make them runnable examples in pkg/sm so a change
to the API or its behaviour breaks the build or the `// Output:` lines.

## Slices

1. `docs: plan for #951` (this file).
2. `test:` pkg/sm/example_docs_test.go (package sm_test), no Host:
   - (a) `ExampleNewCreateFunc`: the guide's `Counter` verbatim, created
     through `sm.NewCreateFunc`; two 8-byte commands and one 3-byte command;
     prints each `Result.Value`, the third being `sm.ResultInvalidCommand`.
   - (b) `ExampleHasher`: `Counter` saves a snapshot into a buffer, a fresh
     `Counter` recovers it; `Lookup` and `GetHash` print the same value; the
     guide's `var _ sm.Hasher = (*Counter)(nil)` is in the file.
   - (c) `ExampleNewCachedDiskStateMachine`: the guide's `CacheConfig` over a
     small in-memory DiskStateMachine with `ExtractKV` and `EntryApplied`;
     applies a command and prints the cached read; MaxEntries 0 prints a
     `*sm.CacheMaxEntriesError`, a nil ExtractKV a
     `*sm.InvalidCacheConfigError`.
3. Per divergence: a failing `test:` commit, then a `fix:` commit in
   pkg/sm/cached.go or pkg/sm/createfunc.go, or a doc correction in
   docs/state-machines/user.md when the code is right.

## Out of scope

- Host-level registration (`host.StartShard`) and `StateMachineHash`.
- Wire or on-disk format versions.

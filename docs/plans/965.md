# Plan for #965: waldb guide snippets as a compiled example

Refs #744 (v1.0.0 bar test gap).

## Objective

docs/log-storage/user.md shows two waldb snippets that no build checks:
opening a WAL with `WithMaxFileSize`, and repairing a damaged segment from a
`*SegmentCorruptionError` with `Repair` and `RepairTarget`. Make both a
compiled example with a checked `// Output:` block, and point the guide at it.

## Slices

1. `docs: plan for #965` (this file).
2. `test: ...` adds pkg/logdb/waldb/example_test.go (package waldb_test):
   - `ExampleOpen`: open a temp dir with `WithMaxFileSize`, `SaveState` one
     update (entries plus hard state), `Close`, reopen, `ReadState` returns
     the saved state.
   - `ExampleRepair`: write entries to one shard, flip a byte in the second
     block of its first segment, `Open` fails with an error matching
     `*waldb.SegmentCorruptionError`; `Repair` with
     `RepairTarget{ShardIndex, SegmentID, TruncateAt: CleanEnd}` and the same
     `WithBlockSize` succeeds; the reopened DB returns the entries before the
     damage.
   The guide's two blocks get a line naming the example.
3. Per divergence between code and guide: a failing test commit, then a fix
   commit (repair.go or db.go), or a guide correction when the code is right.

## Out of scope

Any change to the on-disk format, new Repair behaviour, other guides.

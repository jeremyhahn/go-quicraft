# Plan: #845 Host.LogReader view

## Objective

`Host.LogReader` (pkg/log_reader.go, docs/raft-consensus/api.md "inspect
consensus state") returns a read-only view whose `GetRange` is the first and
last index of the shard's log and whose `NodeState` is the last index and the
current term. The only test checks the reader is non-nil. Pin the contract.

## Slices

1. `docs: plan for #845` (this file).
2. `test:` pkg/host_logreader_view_test.go, single-replica Host
   (newTestHost, testShardConfig, waitForLeader), tests named
   TestLogReaderView*:
   - (a) `GetRange()` equals `LogRange(1)`; `NodeState()` returns
     `(LogRange(1).LastIndex, term)` with `term` from `LeaderIDAndTerm(1)`.
   - (b) a reader obtained before 20 `SyncPropose` calls reports a last
     index at least 20 higher afterwards, in `GetRange` and `NodeState`.
   - (c) after `SyncRequestSnapshot` with a small compaction overhead and
     `RequestCompaction(1, 1)`, `GetRange()` first index equals
     `LogRange(1).FirstIndex` and is above 1.
   - (d) after `StopShard(1)`, `LogReader(1)` returns `ErrShardNotFound`.
3. Per divergence from the docs: a failing `test:` commit, then a `fix:`
   commit in pkg/log_reader.go (or a doc correction in
   docs/raft-consensus/api.md when the code is right).

## Out of scope

- Any change to LogRange, QueryRaftLog or the logdb LogReader.
- Wire or on-disk format versions.

# #924: FollowerRead on a real follower

Refs #744 (v1.0.0 bar test gap).

## Objective

Test the documented contract of `Host.FollowerRead` (docs/multi-group-host/api.md
"FollowerRead") against a real three-replica QUIC shard: a read on any replica
waits until that replica has applied up to the commit index it knows when the
read starts, so it never returns a value older than a write that replica
already knows is committed.

## Contract as documented

- The wait is bounded by **this replica's** committed index, not the leader's.
  A follower learns a commit on the next append or heartbeat, so a read issued
  the instant `SyncPropose` returns on the leader may legitimately miss it
  (the docs say it is not linearizable). The test therefore asserts on reads
  issued once the follower's committed index covers the acknowledged write.
- A cancelled `ctx` yields `ErrCanceled` (docs list `ErrTimeout` / `ErrCanceled`
  from `ctx`). `ErrCanceled` does not wrap `context.Canceled`; the test asserts
  the documented sentinel.

## Slice (one commit)

pkg/host_follower_read_test.go: three QUIC hosts (testpki CA and leaves,
member identities), in-memory kv state machine.

- (a) 50 `SyncPropose` puts on the leader; after each, once each follower's
  committed index reaches the leader's commit index at acknowledgement,
  `FollowerRead` of the key on that follower returns the new value.
- (b) A writer goroutine keeps writing increasing values to one key while
  readers on both followers loop: each read snapshots the last acknowledged
  value and its commit index, waits until the follower knows that index, then
  reads; the result is never older than the snapshot, and successive reads on
  one follower never go backwards.
- (c) `FollowerRead` on the leader returns the latest acknowledged value with
  no wait.
- (d) With a cancelled context a follower's `FollowerRead` returns
  `ErrCanceled`.

A divergence of code from docs would add a failing test commit, then a fix in
pkg/host.go; a doc wrong where the code is right is fixed in
docs/multi-group-host/api.md.

## Out of scope

Partitioned followers, witnesses and observers, and other read APIs.

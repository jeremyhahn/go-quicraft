# #762: the public session errors are the ones the code returns

## Objective

`quicraft.ErrSessionLimitExceeded`, `ErrTooManySessions`, `ErrSessionNotFound`,
`ErrSessionAlreadyExists` and `ErrResponseLimitExceeded` are separate values
from the ones `pkg/internal/session` returns, so `errors.Is` on a returned
session error never matches the public name. Make each public value the
internal value, as `pkg/errors.go` already does for the engine, raft, rsm and
transport aliases. `ErrTooManySessions` stays an alias of
`ErrSessionLimitExceeded`.

## Slices, in order

1. This plan.
2. Test (fails): `pkg/errors_session_alias_test.go` checks identity and
   `errors.Is` both ways between each public value and the session manager's
   value, through wrapping, and against the error a real session manager
   returns for each case.
3. Fix: in `pkg/errors.go` assign the public vars from `session.*`; the
   internal messages take the `quicraft:` prefix (as `rsm.ErrSessionPolicyMismatch`
   does) so the public text is unchanged and the sentinel prefix test holds;
   drop the five session entries from the allowlist in
   `pkg/errors_exported_test.go`.

## ErrShardNotStarted

Every path that sees a registered-but-not-started shard already returns
`ErrShardNotReady`; switching one of them would split one state over two
errors. It stays allowlisted with that reason.

## Out of scope

No wire or on-disk format change; no other exported error.

# Plan for #932: async RequestUpdateWitnessPolicy

Refs #744 (v1.0.0 bar test gap).

## Objective

`RequestUpdateWitnessPolicy` (pkg/host.go) is the async form of
`SyncRequestUpdateWitnessPolicy`. docs/membership-changes/api.md says the
change goes through Raft, a policy the current membership violates is refused
with `ErrTooManyWitnesses` or `ErrBreaksFullReplicaMajority`, and
`configChangeIndex` is the staleness guard (0 skips it). The sync form is
covered by pkg/host_witness_policy_test.go; the async form only with an
invalid policy. This row covers the async form end to end.

## Slices

1. This plan.
2. pkg/host_witness_policy_async_test.go, on newWitnessPolicyCluster:
   - (a) a valid policy that loosens the current one returns a non-nil
     RequestState whose Result completes without error; every replica then
     reports it through ShardMembership.
   - (b) with two witnesses, tightening to MaxWitnesses=1 fails with
     `ErrTooManyWitnesses` (from the call or the Result); every replica keeps
     the old policy.
   - (c) a non-zero configChangeIndex read before the last change is refused
     with `*StaleConfigChangeError`; the policy is unchanged.
   - (d) each returned RequestState is released exactly once: not released
     before the test's single Release, released after it.
3. Per divergence from the docs: a failing test commit, then a fix commit in
   pkg/host.go (or a doc fix in docs/membership-changes/api.md when the code
   is right).

## Out of scope

- The sync form (already covered), restart persistence, any wire or on-disk
  format change, and any file outside the brief's file map.

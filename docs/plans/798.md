# #798: export from one Host, import into a fresh Host, same state

Objective: prove end to end that ExportSnapshot of a shard holding real applied
entries imports into a fresh Host and restarts at the same state hash, and that a
one-byte flip in the exported file is refused without touching the target tree.

Already covered (cited, not repeated): artifact framing and trailer round trip on
synthetic payloads (pkg/snapshot_artifact_trailer_test.go:239), damaged-artifact
refusals (:279), cross-host import of an empty state machine
(pkg/host_test.go:5300).

Slice 1 (pkg/snapshot_export_import_test.go, new):
- TestExportImport_FreshHostSameStateHash: KV store, proposals,
  SyncRequestSnapshot, ExportSnapshot to a temp file; fresh Host imports it,
  StartShard, StateMachineHash equals the source hash.
- TestExportImport_FlippedByteRefusedTargetUnchanged: flip a payload byte;
  ImportSnapshot fails with *SnapshotArtifactError / ErrSnapshotCorrupt and the
  target Host's directories are byte-identical before and after.

Out of scope: format or version changes; encrypted variants (covered elsewhere).

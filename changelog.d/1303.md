### Added

- Durable by default (#1303): tests now pin that the default `HostConfig` and
  the default write mode acknowledge a write only after a quorum has fsynced
  it. A reflection guard fails when a new `HostConfig` bool has not been
  classified as durability-weakening or neutral, or when a weakening bool
  defaults to on. `docs/durable-by-default/README.md` lists the opt-in
  settings (`NoSyncWAL`, `NotifyCommit`, `writemode.WALDurable`) and what
  each one gives up. No default changes.

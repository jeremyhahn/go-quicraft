### Added

- `RequestState.Wait(ctx)` waits for an asynchronously submitted request and classifies a lost wait as every synchronous host call does: a definite `ErrTimeout` / `ErrCanceled` when the request's queue closed before hand-off, `*MaybeAppliedError` otherwise. (#1229)

### Fixed

- contrib/dragonboat `NodeHost.SyncPropose` with a tracked session and `NodeHost.SyncCloseSession` now report a context deadline or cancellation that ends the wait after the request may have been handed off as `*quicraft.MaybeAppliedError` wrapping `ErrTimeout` / `ErrCanceled` (`quicraft.MaybeApplied` true), as the no-op session path already did; a request whose queue closed before hand-off stays a definite `ErrTimeout` / `ErrCanceled`. `errors.Is` results are unchanged; no wire or format change. (#1229)

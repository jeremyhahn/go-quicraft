### Fixed

- transport: peers with disjoint wire windows now produce a diagnostic naming
  both sides' versions. The early frame-header and batch version refusals
  return typed errors (`FrameVersionError`, `proto.BatchVersionError`, both
  `errors.Is` `ErrUnsupportedVersion`) and are handed to the host's message
  handler, which records and logs a `WireVersionMismatchError` once per peer
  address and version change. No wire or format version changed.

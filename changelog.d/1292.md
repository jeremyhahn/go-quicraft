### Fixed

- Batch aggregator (#1225): a `Submit` whose context ends after `Close` has begun, while its proposal is still queued for the final flush, now returns `*FlushError{Indeterminate: true}` wrapping the context error instead of a bare `context.DeadlineExceeded` or `context.Canceled`. The close path still proposes that batch, so the outcome is unknown; `errors.Is` on the context error still holds.

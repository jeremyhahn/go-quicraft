### Added

- test/clusterproof (#1301): `make test-clusterproof` runs a three-replica cluster as three OS processes with WAL fsync on, SIGKILLs and restarts a random replica each cycle under concurrent writes, and fails if any acknowledged write (fsynced to the writers' ack log before it is counted) is missing from any replica's linearizable state, or if a linearizable read of an acknowledged write does not return it. A linearizable `GET /all` that answers without an acknowledged write fails at once; only an unavailable read is retried. `-clusterproof.cycles` and `-clusterproof.seed` (via `CLUSTERPROOF_ARGS`) set the run; a failure prints the seed. The integration targets and CI's integration shards run the package beside `test/integration`, including a checker test that runs the harness with `-clusterproof.readers=0` and requires the baseline to pass and the negative injection to fail on missing acknowledgements. Test-only: no API, wire or format version changes.
